# 提示词模板（直接粘给 Agent）

这三个文件是**自包含**的：把整个文件内容作为任务提示词粘给任意具备浏览器控制能力（browser-skill / bsk）的 Agent，它就能独立完成任务，不需要再读本仓库其它文档。

## 怎么选

| 场景 | 用哪个 |
|---|---|
| 优学习 / `courseweb.ulearning.cn` / 思政类网课 | [`01-ulearning.md`](01-ulearning.md) |
| 智慧课程 / `smartcourse.hust.edu.cn` / 大学英语词汇课 | [`02-smartcourse.md`](02-smartcourse.md) |
| 其它没见过的课程平台 | [`03-generic-platform.md`](03-generic-platform.md) |

## 使用前要替换的占位符

模板里统一用 `<尖括号>` 标注需要你填的内容：

| 占位符 | 填什么 |
|---|---|
| `<章节列表>` | 要刷的章节，如 `10,12,14,15,16` 或 `Unit 1–4` |
| `<课程名称>` | 课程中文名，用于报告 |
| `<SESSION>` | 一般不用填，Agent 会自己 `bsk session start` 拿 |
| `<TAB_ID>` | 一般不用填，Agent 会自己 `tab list` 找 |

## 使用建议

1. **先让 Agent 只做一章**，确认流程跑通、报告符合预期，再让它批量跑。
2. 提示词里已经写了「报错就停、不要反复重试」——不要删掉这条，否则 Agent 容易在一个坏页面上空转。
3. 如果登录过期，模板里要求 Agent 主动请求人工接管，而不是自己猜密码。
4. 刷完后务必让它输出**逐章验证表**（不是"我以为完成了"），模板里已经强制要求。
